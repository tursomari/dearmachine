# Documentation

This directory contains machine-level reference material that helps future
sessions serve the User.

Appropriate content includes system overviews, conventions, recurring
decisions, caveats, and pointers to useful resources in other projects.
Documentation is descriptive: it explains what something is or how it works.
Step-by-step recurring procedures belong in `../process/`.

Keep project-specific knowledge in its project unless a short machine-level
pointer is repeatedly useful from the entry point.
