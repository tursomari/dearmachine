# Process

This directory contains self-contained runbooks for recurring machine-level
workflows.

A runbook is prescriptive: it explains how to complete and verify a task. Add
one when the workflow crosses projects, manages the machine, has been repeated,
or was explicitly requested as durable operating guidance.

Runbooks may reference files in `../documentation/`, but one runbook should not
depend on another runbook. Project-local procedures remain in their projects.
